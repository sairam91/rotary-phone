# Rotary Phone

A nostalgic iOS app that recreates the classic rotary phone dialing experience with authentic visual design and sound effects.

## Description

This iOS application simulates a vintage rotary phone, complete with:
- Interactive rotary dial with realistic rotation mechanics
- Authentic dial sound effects
- Phone number formatting and display
- Actual phone call functionality when running on a physical device
- Retro visual design with shadows and classic phone aesthetics

The app provides a fun, nostalgic way to make phone calls while experiencing the tactile satisfaction of using a rotary dial.

## Features

- **Authentic Rotary Dial**: Drag-to-rotate interface that mimics real rotary phone behavior
- **Sound Effects**: Includes authentic rotary dial audio for immersive experience
- **Phone Number Display**: Real-time formatting of dialed numbers (___-___-____)
- **Call Functionality**: Integrates with iOS phone capabilities to make actual calls
- **Visual Polish**: Realistic shadows, gradients, and styling for authentic look
- **Clear Function**: Easy number clearing and re-dialing

## Requirements

- iOS 13.0+
- Xcode 12.0+
- Swift 5.0+
- Physical iOS device recommended for phone call functionality

## Installation

1. Clone this repository
2. Open `RotaryPhone.xcodeproj` in Xcode
3. Build and run on your iOS device or simulator

## How to Contribute

We welcome contributions to make this rotary phone experience even better! Here's how you can help:

### Getting Started

1. **Fork the repository** on GitHub
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/your-username/rotary-phone.git
   cd rotary-phone
   ```
3. **Create a feature branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```

### Making Changes

1. Open `RotaryPhone.xcodeproj` in Xcode
2. Make your changes following the existing code style
3. Test thoroughly on both simulator and physical device
4. Ensure your code follows Swift best practices

### Submitting Changes

1. **Commit your changes** with clear, descriptive messages
2. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
3. **Create a Pull Request** from your fork to the main repository
4. Provide a clear description of your changes and why they're needed

### Contribution Ideas

- **Visual Enhancements**: Improve the rotary dial appearance or animations
- **Sound Improvements**: Add more authentic audio effects or haptic feedback
- **Accessibility**: Add VoiceOver support and accessibility features
- **Performance**: Optimize animations or memory usage
- **Features**: Add contact integration, call history, or speed dial functionality
- **Bug Fixes**: Report and fix any issues you encounter

### Code Style Guidelines

- Follow Swift naming conventions
- Use clear, descriptive variable and function names
- Add comments for complex logic
- Maintain the existing architecture patterns
- Test on multiple device sizes

### Reporting Issues

Found a bug or have a feature request? Please create an issue on GitHub with:
- Clear description of the problem or enhancement
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Device and iOS version details
